# Agent Roster

## harness_pr_coordinator

Coordinates worktrees, granular commits, draft PR opening, evidence collection, and QA/HITL handoff.

## backend_engineer

Implements backend services, APIs, auth, wallet abstraction, Pix/on-ramp, Polymarket adapters, relayer, and indexer.

## frontend_engineer

Implements web/mobile-first frontend, UI states, accessibility, and backend/wallet abstraction integration.

## product_designer

Owns flows, copy, visual consistency, non-Web3 UX, and design evidence.

## blockchain_engineer

Implements EVM contracts, EIP-712, ERC-2612, BRL1 escrow, template allowlists, and Polymarket CTF resolution.

## blockchain_query_operator

Runs repository read-only blockchain query scripts and records technical evidence.

## qa_reviewer

Runs local QA, validates Definition of Done, finds gaps, and blocks progress when evidence is insufficient.

## security_reviewer

Reviews keys, permissions, abuse cases, privacy, smart contracts, dependencies, and threats.

## docs_maintainer

Keeps documentation lean, discoverable, current, and consistent with the operating model.
